1. Pengantar Proyek

Proyek ini dikembangkan dengan identitas khas Media Samudera Kepri untuk menghubungkan transparansi jurnalistik dengan pencatatan bukti digital di jaringan EVM. Saat ini seluruh fitur diuji secara terstruktur di jaringan Ethereum Sepolia (Chain ID: 11155111) sebelum dipindahkan ke sistem Ethereum asli.

2. Empat Pilar Utama Sistem

Setiap komponen dirancang saling melengkapi agar dapat diaudit publik secara terbuka:

Berita Berbasis Blockchain

Penyegelan contentHash (bytes32) untuk arsip berita, gelar fakta, dan investigasi.

Coin Samudera Kepri (MSK)

Token ekosistem untuk mendukung partisipasi, apresiasi, dan transparansi komunitas.

NFT Arsip & Bukti

Sertifikat digital dan koleksi NFT arsip edisi khusus milik ekosistem Samudera Kepri.

Media Samudera Kepri

Integrasi rujukan publikasi ke samuderakepri.co.id serta portal komunitas.

4. Contoh Pembacaan Status Fakta (verifyFact)

Contoh pembacaan keaslian hash berita menggunakan ethers.js v6:

JAVASCRIPT · ETHERS V6 
const RPC_URL = "https://rpc.sepolia.org";
const FACT_SEAL_ADDR = "0xbAED3a7fb42736d6597145FAE88b3c9a00d5a033";
const ABI = [
  "function totalSealed() view returns (uint256)",
  "function verifyFact(bytes32 contentHash) view returns (bool exists, bool isValid, string referenceUri, string category, address verifier, uint64 timestamp, string revokeReason)"
];

const provider = new ethers.JsonRpcProvider(RPC_URL);
const contract = new ethers.Contract(FACT_SEAL_ADDR, ABI, provider);
const total = await contract.totalSealed();
console.log("Total data tersegel:", total.toString());

5. Jalur Menuju Sistem Ethereum Asli

Seluruh halaman, alur verifikasi berita, modul NFT, dan utilitas coin MSK disempurnakan terlebih dahulu di lingkungan uji. Setelah seluruh komponen teruji matang dan siap, konfigurasi jaringan, alamat kontrak, serta rujukan resmi akan dimigrasikan ke sistem Ethereum asli.
